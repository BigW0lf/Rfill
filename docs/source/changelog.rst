Changelog
=========

Version 1.0.0 — 27 avril 2026
-------------------------------

Première version publique.

* Import AutoCAD (``.xls``) et GeoGex (``.xlsx``).
* Éditeur de catégories par glisser-déposer avec sur-catégories.
* Export Excel multi-feuilles avec mise en forme complète.
* Rapport HTML imprimable A4 paysage (logos, tampon, onglets écran).
* Glossaire interne modifiable et persistant.
* Exécutable autonome Windows généré par PyInstaller + Inno Setup.
